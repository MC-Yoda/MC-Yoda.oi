Как пользоваться на Android-смартфоне

Способ 1. Мгновенная установка без Android Studio (PWA): откройте этот файл в браузере Chrome на Android, нажмите меню «⋮» → «Добавить на главный экран». Приложение появится среди иконок на телефоне и будет работать офлайн с сохранением всех смен.
Способ 2. Сборка нативного APK в Android Studio: вместе с этим приложением подготовлен архив SalaryCalculatorAndroid.zip с исходным кодом на Kotlin + Jetpack Compose. Откройте папку проекта в Android Studio и выберите Build → Build APK(s).
