# Альфа • Мотивация и ЗП (Android-приложение с расчетом НДС 13%)

Полный проект Android-приложения со встроенным интерфейсом калькулятора мотивации (все 32 позиции, расчет ИТОГО ЗП с НДС 13%, журнал смен, обычный калькулятор и таблица условий).

## Вариант 1. Облачная сборка APK без установки программ (через GitHub)
В проект уже встроен автосборщик `.github/workflows/build-apk.yml`:
1. Создайте бесплатный репозиторий на GitHub и загрузите туда файлы из этого архива.
2. Перейдите на вкладку **Actions** -> запустите **Build Android APK**.
3. Через 1–2 минуты скачайте готовый установочный файл `app-debug.apk` в разделе **Artifacts**.

## Вариант 2. Сборка в 1 клик через онлайн-конвертер (WebIntoApp)
Файл `app/src/main/assets/index.html` полностью автономен:
1. Откройте сайт https://www.webintoapp.com/
2. Загрузите файл `index.html`, укажите название `Альфа Мотивация и ЗП` и нажмите **Make App** — сайт сразу выдаст готовый `.apk` файл.

## Вариант 3. Сборка в Android Studio на ПК
1. Откройте папку `SalaryCalculatorAndroid` в Android Studio.
2. В меню выберите **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
3. Заберите готовый `app-debug.apk` из `app/build/outputs/apk/debug/`.
